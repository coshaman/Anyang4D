# Scenario triage model bundle

The bundle is a CPU-only scikit-learn tabular surrogate. It is valid only for explicit administrative scenarios and requires exact verification for final values. `model.joblib` and `metadata.json` are generated by:

```powershell
.venv\Scripts\python.exe scripts/ai/train_goal5a.py
```

The model is not a citizen guidance, flood prediction, damage prediction, probability, or official forecast system.
