# Anyang Level-A model boundary after RESET

The existing deterministic engine remains the only permitted Level-A engine. If and only if derived-vector terrain passes the reset quality gates, it may consume that terrain with hypothetical rainfall and emit `RELATIVE_HAZARD(x,y,t)`.

It must not emit `WATER_DEPTH_M`, official forecast values, flood probability, or safe-route recommendations. The current 2025 DXF audit alone is not sufficient to activate the real Anyang field.
