# Goal 3A — Flood model and license audit

Audit date: 2026-08-21. Statuses mean `GO` = license evidence sufficient for evaluation, `CONDITIONAL` = use only with stated restrictions, `HOLD` = do not vendor or deploy, `DROP` = unsuitable for the current claim.

| Component | License evidence | Status | Goal 3A decision |
| --- | --- | --- | --- |
| PhysicsNeMo | NVIDIA repository states Apache License 2.0 and links `LICENSE.txt` | GO | Preferred framework for an isolated physics-informed surrogate spike |
| EPA SWMM solver | Official EPA repository describes the source as Public Domain | GO | Suitable teacher/benchmark engine, but not a city model without drainage inputs |
| PySWMM | Repository contains a BSD-2-Clause license | CONDITIONAL | Optional Python wrapper; not required for the current proof |
| LarNO source | GitHub README says MIT, but the repository file listing inspected for this audit did not expose a root license file | HOLD | Obtain and archive an authoritative license file before vendoring or shipping source |
| LarNO weights/dataset | Hugging Face cards label the model and dataset MIT, but benchmark labels were generated by commercial MIKE+ and are Shenzhen/UKEA data | CONDITIONAL | Benchmark-only reproduction; never call it Anyang truth |

PhysicsNeMo provides the relevant neural-operator/PINO and shallow-water examples, but its availability does not supply Anyang data or validation. SWMM is a drainage-system simulator; an `.inp` file made from guesses would be a synthetic plumbing test, not an Anyang hydraulic teacher.

Sources: [PhysicsNeMo repository](https://github.com/NVIDIA/physicsnemo), [EPA SWMM repository](https://github.com/USEPA/Stormwater-Management-Model), [PySWMM repository](https://github.com/pyswmm/pyswmm), [LarNO source repository](https://github.com/holmescao/LarNO), [LarNO model card](https://huggingface.co/holmescao/LarNO), and [LarNO benchmark dataset card](https://huggingface.co/datasets/holmescao/LarNO-dataset).
