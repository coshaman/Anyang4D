# LarNO evaluation

Status: `HOLD` for product vendoring; `CONDITIONAL` for benchmark-only study.

The published card describes 13 inputs (rainfall, cumulative rainfall, DEM) and one-step water-depth output. Its released UKEA and Futian/Shenzhen data are benchmarks, with labels generated by the commercial MIKE+ solver; they are not Anyang observations. The repository README claims MIT, while the inspected GitHub file listing did not expose a root license file. Until the license file and separate weight/data terms are archived, no LarNO source or weights are copied into this repository.

If later approved, the reproduction must record exact checkpoint hash, input tensor dimensions, output dimensions, event/domain, and `BENCHMARK` provenance. It cannot be described as Anyang validation.
