# Goal 3B demo AOI

The automatically selected demo AOI is a compact rectangle around a dense central Anyang facility/network area:

- WGS84 bbox: longitude `126.946`–`126.966`, latitude `37.376`–`37.396`
- Approximate size: 1.8 km × 2.2 km
- Selection evidence: 71 shelter records, 10 emergency-water records, 4,382 OSM pedestrian nodes
- Selection provenance: `SELECTION_ONLY`; OSM and facilities were used for presentation value and coverage, not hydrological risk inference
- GeoJSON: `artifacts/evals/data/demo-aoi.geojson`

The AOI intersects four unique latest 1 m metadata tiles. The precise minimum set is documented in `docs/NGII_DEM_DOWNLOAD_REQUEST.md`.
