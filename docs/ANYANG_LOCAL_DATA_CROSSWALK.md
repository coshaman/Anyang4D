# Anyang local / national crosswalk

The current municipal shelter board was captured page-by-page and parsed into 224 unique local records. The filtered national standard dataset contains 231 Anyang shelter records. Coordinate-nearest matching uses a conservative 100 m threshold and keeps names, addresses, coordinates, and provenance from both sources.

Current classifications: 24 exact, 147 strong, 0 ambiguous, 53 local-only, and 60 national-only. These are review/audit relationships, not deduplicated operational facilities.

Local emergency-water data contains 46 records, including official daily-tonnage and available-person fields. Local flood-response inventory contains 33 records. Both remain context inputs; inventory is not automatically dispatched and water capacity is not converted into evacuation capacity.
