# AI scenario feature schema

Features are available before assignment solving: disaster-type indicators, explicit participation, keyframe count, population/affected-demand summaries, hazard bounding-box proxy, closure count/length/degree aggregates, available shelter count, available capacity, closed shelter count, lost capacity, and capacity-to-demand ratio.

No assignment, unserved, travel cost, facility load, bottleneck, or other post-solve value is used as a feature. Static graph descriptors are computed once and closure aggregates are derived from them.
