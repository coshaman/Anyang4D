# 기존 서비스와의 기능 비교

이 표는 기존 공공 안전 서비스의 가치를 낮추기 위한 비교가 아니라, SAFE-Twin의 사용 질문이 다름을 설명하기 위한 것이다. 특정 기관의 기능은 공고·버전에 따라 달라질 수 있으므로 확인되지 않은 제품 기능은 단정하지 않는다.

| 비교 축 | 알림·안전정보 서비스 | 시설 조회 서비스 | SAFE-Twin Anyang |
|---|---|---|---|
| 기본 목적 | 경보·행동 정보 전달 | 시설 위치·연락 정보 제공 | 행정 What-if 비교·기록 |
| 시간에 따른 가정 상태 | 일반적으로 핵심 기능 아님 | 일반적으로 핵심 기능 아님 | frame마다 도로·시설·수요 재계산 |
| 수용량 제약 assignment | 일반적으로 제공하지 않음 | 시설 정보 제공 중심 | exact min-cost flow |
| Scenario A/B | 일반적으로 제공하지 않음 | 일반적으로 제공하지 않음 | 시설 outage 등 fixed A/B |
| 많은 후보 선별 | 일반적으로 제공하지 않음 | 일반적으로 제공하지 않음 | AI ranking shortlist |
| 최종 검증 | 안내 정보의 출처에 의존 | 제공 데이터의 출처에 의존 | top-K exact reference 재계산 |
| 시민/관리자 경계 | 시민 안내 중심 | 시민 조회 중심 | 시민 정보와 관리자 가정 시뮬레이션 분리 |

SAFE-Twin은 시민에게 가정 hazard를 공식 안전 경로로 제공하지 않는다. 따라서 이 비교의 핵심은 “더 좋은 알림”이 아니라 “행정자가 조건을 바꿔 결과를 비교하는 계산 workflow”다.
