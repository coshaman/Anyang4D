# 제출 전 사람만 수행할 체크리스트

- 각 제공기관의 재배포·출처표시 조건을 최종 확인한다. 특히 NGII raw DXF/DEM은 공개 패키지에서 제외한다.
- 신청자·팀명·연락처·소속 등 현재 자료로 추론할 수 없는 identity 필드를 공식 양식에 입력한다.
- 서명·직인·동의가 필요한 항목을 사람이 처리한다.
- 공식 PDF/HWPX에 콘텐츠 마스터를 옮긴 뒤 페이지 수, 글자 크기, 그림 해상도와 깨짐을 최종 검토한다.
- 제출 파일 크기 제한과 제출 채널을 공식 공고에서 확인한다.
- 공개 패키지에 raw NGII, 비공개 source, `.env`, key, local cache가 들어가지 않았는지 확인한다.
- 최종 제출 전에 `/admin?demo=1` 시연 순서와 발표용 로컬 환경을 점검한다.
- 고해상도 DEM 확보는 릴리스 의존성이 아니며, `docs/HIGH_RES_DEM_FINAL_DECISION.md`의 경계를 발표·서식 문구와 대조한다. `FLOOD`는 `가정 침수영역에 따른 영향 시뮬레이션`으로만 설명한다.
- 공식 HWPX 작성본의 `[사람 입력 필요]` identity 필드, 서명/동의/직인, 재학·소속 증빙은 제출자 본인이 확인·완료한다. 시스템은 이름·연락처·서명을 추정하지 않는다.
