# Product direction after terrain-derived flood path drop

The 2025 NGII vector-derived terrain remains `TERRAIN_C` diagnostic evidence. The street-level terrain-flood path is permanently dropped for this project. Goal 4A instead provides administrative what-if analysis over manually defined hazard geometry, dynamic roads, facilities, demand assumptions, and resources.

Flood remains a supported disaster type only as `가정 침수영역`/`시나리오 침수영역`. No terrain-predicted flood map, predicted water depth, AI flood forecast, or citizen emergency route is produced.

The next product architecture should prioritize official/admin hazard polygons, time-dependent road closures, shelter capacity, demand, facility outages, and response-resource allocation. A future operational path would require a separate authoritative-source authorization gate.
